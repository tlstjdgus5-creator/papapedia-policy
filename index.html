PAPAPEDIA Uploader 개인정보처리방침

시행일: 2026년 10월 7일

1. 이 앱에 대하여

PAPAPEDIA Uploader(구글 클라우드 프로젝트 papapedia-uploader)는 유튜브 채널 육아대사전(papapedia)과 잡학왕조실록의 운영자가 자기 채널을 관리하려고 만든 개인용 도구입니다. 일반 사용자에게 제공하는 서비스가 아니며, 운영자 본인의 구글 계정으로만 로그인해 사용합니다.

2. 유튜브 API 서비스 사용

이 앱은 YouTube API 서비스를 사용합니다. 이 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. 구글이 정보를 처리하는 방식은 Google 개인정보처리방침을 따릅니다.

3. 접근하는 정보와 쓰는 곳

  • 영상 업로드(youtube.upload): 운영자가 만든 영상을 자기 채널에 올립니다.
  • 채널 영상 관리(youtube, youtube.readonly): 자기 채널 영상의 제목·설명·재생목록·공개 상태·예약 시각을 정하고, 영상 목록과 상태를 읽습니다.
  • 통계 보기(yt-analytics.readonly): 자기 채널 영상의 조회수 등 통계를 읽어 운영자의 제작 현황판에 보여 줍니다.

이 앱은 운영자 본인 채널의 정보만 다룹니다. 다른 사람의 개인정보나 시청자 정보를 모으지 않습니다.

4. 저장과 공유

  • 로그인 정보(OAuth 토큰)는 운영자 컴퓨터 안에만 저장하며 외부 서버로 보내지 않습니다.
  • 채널 영상 목록과 통계는 운영자 컴퓨터의 현황판 파일에만 저장하고, 현황판을 실행할 때마다 유튜브에서 다시 받아 갱신합니다.
  • 받은 정보는 판매하거나 광고에 쓰거나 제3자와 공유하지 않습니다. 구글 API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
  • 이 페이지 자체는 아무 정보도 모으지 않습니다. 페이지는 GitHub Pages에서 제공되며, GitHub의 접속 기록은 GitHub 개인정보 처리방침을 따릅니다.

5. 권한 철회와 삭제

구글 계정의 보안 설정 → 서드파티 앱 및 서비스에서 언제든 이 앱의 접근 권한을 끊을 수 있습니다. 권한을 끊거나 운영자가 요청하면 운영자 컴퓨터에 저장된 토큰과 현황판 정보를 지웁니다.

PAPAPEDIA Uploader Privacy Policy

Effective date: October 7, 2026

1. About this app

PAPAPEDIA Uploader (Google Cloud project papapedia-uploader) is a personal tool built by the operator of the YouTube channels 육아대사전 (papapedia) and 잡학왕조실록 to manage their own channels. It is not offered to the public and is used only with the operator's own Google accounts.

2. Use of YouTube API Services

This app uses YouTube API Services. By using this app, you agree to be bound by the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

3. What the app accesses and why

  • Upload videos (youtube.upload): uploads videos made by the operator to their own channel.
  • Manage channel videos (youtube, youtube.readonly): sets titles, descriptions, playlists, privacy status and scheduled publish times of the channel's own videos, and reads the channel's video list and status.
  • View statistics (yt-analytics.readonly): reads view counts and similar statistics for the channel's own videos to show them on the operator's production status board.

The app only handles data about the operator's own channels. It does not collect personal information about other people or viewers.

4. Storage and sharing

  • Sign-in credentials (OAuth tokens) are stored only on the operator's own computer and are never sent to any other server.
  • The channel's video list and statistics are stored only in the status board files on the operator's computer and are refreshed from YouTube each time the board runs.
  • Data is never sold, used for advertising, or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • This page itself collects no information. It is served by GitHub Pages; GitHub's access logs are covered by the GitHub General Privacy Statement.

5. Revoking access and deletion

You can revoke this app's access at any time from your Google Account's security settings (Third-party apps & services). When access is revoked or on request, the tokens and status board data stored on the operator's computer are deleted.
